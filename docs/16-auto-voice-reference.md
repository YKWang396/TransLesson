# 0.1.7：自动填写克隆参考原声

更新日期：2026-10-31。

## 原生启动 GPT-SoVITS API

在 GPT-SoVITS 整合包根目录打开 PowerShell，直接运行：

```powershell
$env:PATH = "$PWD\runtime;$env:PATH"
.\runtime\python.exe -I api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml
```

第一行让服务找到整合包自带的 FFmpeg。窗口显示 Uvicorn running 后，课译使用的地址为 `http://127.0.0.1:9880`；可用浏览器打开 `http://127.0.0.1:9880/docs` 检查。保持 PowerShell 窗口开启，停止时按 Ctrl+C。如果 9880 已有服务运行，先停止已有实例，再手动启动，避免重复加载模型。

`go-webui.bat` 用于启动 GPT-SoVITS 网页操作界面；课译连接的是上面独立启动的 `api_v2.py`，两者用途不同。当前本机 v2ProPlus 整合包的默认模型配置已通过 RTX 4070 SUPER/CUDA 推理验证。

## 自动参考声音

转写课程后，进入“03 配音 → 选择说话人 → 配置选中说话人”。选择“参考原声音色 · 本地 GPT-SoVITS”后，时间、参考原话和语言会自动带入。优先使用当前选中的合适原句，否则从同一说话人的课程原文选择 3–10 秒片段，优先 4–8 秒。参考使用原话，目标译文仍由配音读法字段提供。

点击“回听这段原声”检查清晰度、转写和说话人；确认声音使用授权后保存，再试听一段配音。系统生成时会自动提取参考 WAV，无需另导出音频或复制参考文字。

“自动选取并填写”可重新应用建议。已有的手动参考时间、原话和语言在打开窗口时保留。修改参考时间后，程序会尝试重新匹配原话；无法可靠对应时清除上一段的文字并提示，避免音频与文本错配。主动修改原话的输入优先保留。

## 对应关系与限制

- 连续短段只能在同一说话人内部拼接，长停顿和其他说话人会阻断选择。
- 长于 10 秒的整段只有存在匹配的 ASR 逐词时间时，才可截取一小段并同步选择对应文字；不会保留整段文字却只截前 10 秒音频。
- 逐词证据须同时匹配原媒体指纹和标准音轨指纹。原文改写后如果已与原识别词序不符，不使用旧词时间猜测新文本的切点。
- 语言按课程与原话带入，仍可修改。仅凭文字和时间不能保证没有背景音乐、抢话或识别错误，建议保存前回听。
- 自动填写不调用文本 API；选择和保存参考不会自动修改其他说话人的声线。

## 验证

215 项测试通过；原生设置窗口验证自动填写、时间变化后的文字更新、旧文字清理、保留手动设置和回听回调。真实 407 句与 410 句课程均能自动获得合适时长的参考；常规选择耗时小于 0.1 秒。

使用自动选取的 6.02 秒英语课程原声和对应文字，调用本机真实 v2ProPlus 服务生成中文 WAV 成功，本次样例约耗时 2.74 秒。音色相似度和整课自然度仍需试听；单个样例耗时不代表整课性能。
