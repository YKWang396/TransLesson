# 产品范围

课译TransLesson 面向有本地课程翻译需求的教师、学生和内容制作者。当前平台为 Windows x64，支持中文与英语课程。

核心流程：导入视频 → 识别或导入原文 → AI 断句与翻译 → 校对 → 目标语言配音 → 教学讲义 → 导出。

课程数据保存在独立项目中。原文、译文、字幕、读法、数学表达、术语和来源分别保留；任务可以取消、恢复，编辑后仅重算受影响内容。

文本服务可配置，媒体和模型运行在本机。没有文本接口时仍可人工填写字幕；没有参考音色组件时可使用 Windows 声音。

数学内容应保留数字、变量、运算顺序、否定和论证条件。无法确定的公式进入问题清单，允许明确保留原始证据。讲义提炼课程知识结构，并保留来源引用。

当前不提供画面内板书重制、完整手写公式自动识别、重叠人声分离或模型训练界面。多人归属、声音表现和翻译质量需要抽查。
