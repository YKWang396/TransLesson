# 产品需求与边界

## 1. 核心用户与任务

学习者或课程分享者，把有使用权限的本地课程视频转为另一种语言，尤其要保留数学意义、可读公式、教学节奏与可核对的学习资料。

首版核心素材是单个主讲人的中英数学课程录像。输入以 MP4/MKV/MOV 中的常见编码为主，通过实际安装的 FFmpeg 探测是否能解码。不以扩展名判断支持性。

## 2. 必须支持的完整路径

1. 选择本地视频，显示时长、分辨率、音轨、估计存储空间与模型状态。
2. 选择源语言、目标语言、配音方式和导出目录；支持中文→英语、英语→中文。
3. 自动提取音频、识别带时间戳的原文，采样课件或板书关键帧。
4. 结合上下文抽取术语、数学表达和视觉公式候选，生成可编辑课程词表。
5. 翻译成目标语言，保留与原句、公式和来源的映射。
6. 自动生成目标语言字幕、配音和讲义草稿，展示真实阶段进度。
7. 用户可逐句校对、查看公式截图与原文、试听单句或短片，修改后局部重算。
8. 导出翻译视频、SRT/VTT、讲义 PDF；可选 ASS 字幕和编辑用项目数据。

视频生成应保留原画面，尽量保留原背景音。音色相似配音是可选增强能力；标准目标语言配音必须是可用的降级路径。未安装音色克隆模型不阻止使用字幕、标准配音或讲义功能。

## 3. 数学课程要求

- 语音中的数学表达尽量转换为 LaTeX，同时保存原始听写和读法。例如 `x squared plus two x plus one` → `x^2 + 2x + 1`，`e 的 x 次方` → `e^x`，`对 x 求偏导` → `\frac{\partial}{\partial x}`（仅在上下文明确这是算子时）。
- 课件、板书、手写内容中的公式与语音都进入候选池；无法辨认的部分保留原图并标注待校对。
- 同一课程维护一份术语表。例如 derivative→导数、partial derivative→偏导数、integral→积分、eigenvalue→特征值、vector space→向量空间。词义冲突按上下文确认，不做机械字符串替换。
- 字幕与讲义使用适合各自载体的公式呈现；SRT/VTT 不承诺 LaTeX 自动排版。
- 讲义分出课程可追溯内容与补充解释，不把推测当成老师讲过的结论。

## 4. 桌面交互

保持一个主窗口：项目设置、处理进度、字幕/公式校对、试听与导出。允许保存项目、关闭后恢复、取消任务、重试失败步骤。首版同一时刻仅处理一个项目，不做分布式任务调度。

不在原视频上直接覆盖翻译板书/PPT；识别出的数学内容进入校对与讲义。翻译画面中的文字和重制课件属于后续范围。

## 5. 明确不做

登录、付费、社交、实时协作、云端多用户、复杂权限、模型训练、直播同传、自动下载网课、通用视频剪辑器、口型同步、多人逐人高保真音色复刻。

首版不承诺：所有手写公式正确、复杂证明无误、原背景声完美分离、跨语言完全相同音色、普通笔记本实时处理。出现重叠说话或大量学生提问时，应提示适用范围，并可切换统一标准配音。

## 6. 自动化与校对的关系

“开始处理”后自动生成全部草稿与可试听片段。需要确认的公式不会无限阻塞后台任务，而是带警告进入结果。

正式视频/PDF 导出前，如果有未确认的高风险公式、译文缺失、时间轴冲突或配音失败，显示明确项目级问题列表。数学警告可逐项确认保留原图/原文；结构错误、缺失必要音轨或无效输出路径必须修复。每次导出保存当时的警告确认记录。
