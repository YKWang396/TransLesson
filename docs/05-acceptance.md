# 验证标准

每次交付需要通过自动回归、桌面交互、源码运行和打包程序检查。

| 范围 | 检查 |
|---|---|
| 项目 | 创建、保存、重新打开、迁移重连、历史与撤销；原始文件保持完整 |
| 识别 | 本地模型实际载入，返回原文、时间和进度；缺少模型时明确报错 |
| 文本 | 断句不丢字或重排，翻译不改变 ID 和公式引用，讲义保留来源 |
| 费用与隐私 | 默认拒绝外发、预算共享、取消后结算、按接口隔离 Key |
| 配音 | 真实合成、有效语音、内容筛查、时间匹配、失败句定位及重试 |
| 导出 | 字幕与音视频时长有效，PDF 可读取，视频完整解码，依赖哈希正确 |
| 桌面 | 长课程可编辑、切换项目可恢复、问题可定位、任务期间界面可响应 |
| 便携包 | 移除开发工具 PATH 后仍能启动、调用 worker 并导出 |

工程检查不替代数学和听感验收。抽查应覆盖变量、数值、否定、条件、公式读法、句首句尾及课程末尾；多人和中英两个方向分别记录。没有账户 Key 的平台可验证协议，但不能记为真实账户验收。

执行方法见 [开发与验证](development.md)，本次结果见 [验证记录](testing.md)。
