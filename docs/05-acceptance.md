# 验收标准与测试素材计划

所有阈值是拟定产品目标，**没有在本次设计中完成模型实测**。发布时记录样本数、输入条件、模型版本和失败案例；不以通用榜单替代本应用的数学课程测试。

## 1. 测试素材

使用自录或已获许可素材：中→英、英→中各3段，覆盖微积分、线性代数、概率；每段2–5分钟，包含清晰PPT和板书。另有10分钟基准、30–60分钟长课做稳定性测试。

至少人工标注100句口语数学、100个公式裁剪、50处术语出现。训练/提示调优素材与保留测试集分开，歧义有多候选标注，手写和清晰印刷分别统计，不把容易样本的平均值当成手写表现。

关键难例：`1/x+1`与`1/(x+1)`、`-x^2`与`(-x)^2`、`e^x`与`ex`、偏导与全导数、积分上下限、矩阵维度、量词、充要条件、否定、口误后纠正、板书擦除与遮挡。不得无依据补函数、证明步骤或结论。

## 2. 功能与质量门槛

| 项目 | 建议验收方式与目标 |
|---|---|
| 闭环 | 一个本地视频自动生成可编辑项目、目标配音、字幕、翻译视频、讲义PDF；中英两个方向都跑真实样片 |
| ASR | 记录英语WER/中文CER及数学关键词错误，另核数学符号/否定/条件；不只看总字错率 |
| 清晰视觉公式 | 保留集Top-1结构正确率目标≥90%；归一化LaTeX后仍人工核结构；手写结果单列 |
| 高风险公式 | 预定义高风险样例全部进入复核队列，同时报告误报数；不是泛化到所有公式的100%保证 |
| 已确认公式 | 100%可渲染且与人确认内容一致；人工核语义，不能只看渲染成功 |
| 术语 | 正确概念匹配的锁定词条无未经解释变体；误匹配/漏检另外统计 |
| 翻译忠实 | 全查测试集数学公式/定义/条件/结论，不存在已知关键含义错误；普通句另抽样 |
| 字幕 | cue在视频范围内、按时间排序，单讲者首版不重叠；无丢句，读速超限标记，公式可读 |
| 配音时序 | 拟定句起始对计划时间偏差P95≤300ms，所有段不超下一段/相关公式有效窗口，无累计漂移；明确测的是配音排布，不是逐字等长 |
| 配音内容 | 无漏词、重复、截尾；术语和公式自然读法正确；长句失败必须可局部修复 |
| 音色增强 | 中英双向源/译A/B试听，记录人类可懂度、自然度和相似度；必须用户接受，embedding只作辅助 |
| 背景声 | 含背景的至少3处试听无明显原语人声干扰/刺耳伪影；失败时标明实际降级策略 |
| 讲义忠实 | 核心公式/定义/命题100%有有效来源，并逐条回查支持关系；其他陈述随机至少20条，无已知凭空推导 |
| PDF | 逐页渲染至少150dpi人工检查，无乱码、遮挡、裁切、异常空页；字体嵌入，页末长式和高矩阵正确分页 |
| 视频 | FFprobe可读、音视频轨存在、总时长与快照计划相符；正常/静音/末尾段全程可解码检查 |

不能以低温度、自报confidence、回译分数、两次同模型同意等代替数学正确性验证。统计同时报告自动初稿正确率和人工校对后残留错误率，不能只展示校对后成绩。

## 3. API质量与费用对照

同一保留集对比离线小模型、Flash非思考、疑难Flash思考三种配置；有必要时加用户选定更强provider。记录：公式结构正确率、歧义召回/误报、术语一致性、无依据补全、人工修订数、时延、输入/输出/图像token、实付估算。

只有测到质量/成本优势才启用自动升级规则。预算命中后不发新调用；请求超时、429、余额不足、鉴权失败、非法JSON均可恢复；重试次数有界。未允许图片上传时，绝不因为文字解析失败而发送截图。完全离线配置不产生外部模型请求；模型下载也必须是单独明确动作。

## 4. 必须通过的工程回归

1. **编辑与迟到结果**：生成配音时编辑译文，未确认的新草稿也受保护；旧结果到达不覆盖新revision，试听标旧缓存过期。
2. **局部重算**：只改一句读法，仅该句TTS和依赖产物失效；改字幕断行不重跑ASR/TTS；改术语定位相关语义，不全局硬替换。
3. **取消和恢复**：在ASR、API、TTS、FFmpeg导出分别停止，保存完成片段；重开后验证缓存继续，无孤儿进程/有效半成品。
4. **路径和磁盘**：中文/空格路径、长路径、只读输入、同名输出、磁盘写满、移动源视频、同名但内容变化。路径越界拒绝，原视频只读。
5. **媒体边界**：VFR、非零起始PTS、多音轨、无音轨、损坏容器、旋转视频、静音课件段、重叠说话。支持范围外要明确提示。
6. **资源异常**：内存/显存不足、GPU库不兼容、模型未下载/损坏、语言声音缺失。可重试/切provider，不悄悄联网。
7. **数学输入安全**：非法宏、超长公式、嵌套宏展开、外部URL、恶意SVG/路径、正文XML字符；不执行模型命令。
8. **来源和快照**：删除被引用公式、伪造来源ID、外部输入变化、导出期间编辑。导出使用固定快照，产物依赖hash正确。
9. **打包验证**：干净Windows无需Python开发环境能启动并处理样片；CPU配置可用；GPU配置在受测硬件验证。

## 5. 性能报告与发布判定

10分钟基准记录机器CPU/GPU/RAM/VRAM、模型文件大小、软件版本、每阶段耗时、峰值资源、缓存命中与取消延时。首跑、复跑、单句编辑三种场景分别测。长课验证不随全长加载整片音视频或无界累积逐帧内存。

先达到稳定、可修正和可理解，再按真实瓶颈优化。没有实测数据时，不承诺“10分钟翻完1小时视频”“所有手写都正确”或固定每课费用。

## 6. 本设计包已验证的范围

`tools/validate-design.ps1` 验证设计数据结构和本地文档链接，不代表应用功能测试。它有正例、无效数据探针和重复公式引用正例。设计文本、契约和样例作为Git提交可评审；实际媒体、模型和PDF仍由后续实现阶段验证。
