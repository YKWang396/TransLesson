更新日期：2026-10-31，当前版本 0.1.9。当前交付是可运行的 Windows 原生桌面开发版本，已实现核心工程流程；设计中的完整产品验收仍有未完成项。新增 [AI 断句、教学讲义与项目恢复](13-ai-course-workflow.md)，操作入口见 [使用说明](08-user-guide.md)，多人声音配置见 [本地语音后端](11-voice-backends.md)，产品质量标准仍以 [验收标准](05-acceptance.md) 为准。

0.1.5 增加 [自动节奏配音与集中试听](14-adaptive-dubbing.md)，真实 407 句课程的 117 项配音时长阻断已自动消除，并完成整课 WAV 混音。真实 v2ProPlus 服务已通过自动参考的跨语言样例推理，音色质量与整课听感仍需试听。

0.1.3 已使用真实课程与 DeepSeek Flash 验证全课语义分段、翻译及教学讲义；独立副本生成 407 个句子／语义分句、12 节讲义。恢复项目上下文、简化预算和 PDF 数学符号字体也已完成。全文数学正确率、完整配音自然度仍未签定。

0.1.2 针对 594 句长课程增加问题定位、批量确认、可撤销分段合并、句后停顿利用及有限加速。普通编辑复用表格，导出检查按需运行。旧规则将 `the x` 等误认为 `e^x` 的问题已修复；已有项目提供严格匹配的清理入口，仅补译受影响句子。无需逐句确认全部字幕才能试配音。原始课程项目未被本轮测试修改。

这里将“有代码实现”“通过某类工程检查”“经过真实数学课程验证”分开记录。合成媒体、接口桩和人工样例不能替代真实课程验收。

## 可直接复核的检查入口

从项目目录执行以下命令。依赖必须已按 Setup 配置；开发测试额外需要 pytest，PDF 测试需要本地 Node.js/MathJax、中文 TTF 和测试依赖。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools\smoke-ui.py
.\.venv\Scripts\python.exe tools\smoke-pipeline.py
$env:QT_QPA_PLATFORM = 'offscreen'
$env:PYTHONPATH = 'src'
.\.venv\Scripts\python.exe -m mathbridge.app --smoke-test
```

`tools/smoke-ui.py` 会把人工接口样例复制到独立 QA 目录后编辑，不改写 `examples/project.json`。生成的界面截图用于排版和交互检查，不是模型效果样本。

`tools/smoke-pipeline.py` 已在本机跑通两个语言方向的工程闭环：生成合成视频、手动提供源字幕及目标译文、调用真实 Windows 系统声音，再经独立 Worker 输出 PDF、SRT/VTT/ASS、WAV/MP4，并检查清单、媒体时长、过期配音拒绝和保留原声导出。它不调用真实 ASR 模型或付费翻译 API。便携包已有本机隔离开发工具 PATH 的检查，仍未通过另一台干净机器安装验收。

回归测试中的合成短片验证媒体工程行为：时长、轨道、片段排布、缓存、取消与文件提交。接口测试中的受控模型响应验证协议和错误处理。两者都不证明真实课程的转写、翻译、音色相似度或讲义忠实度。

## 发布前仍需完成的工作

1. 取得授权的真实数学课素材，分别运行中→英、英→中，记录模型版本、硬件、耗时、ASR 数学关键词错误、翻译忠实度、配音听感和人工修订量。
2. 验证参考音色提供程序和背景声策略，完成真实 A/B 试听；若不具备，应继续以标准声音基础版本标识。
3. 补齐普通用户可配置的本地 OCR 与离线文本模型生命周期，验证复杂手写及高风险公式。
4. 对 10 分钟基准、30–60 分钟长课测试资源、停止、恢复、源媒体迁移及导出期间编辑。
5. 对已生成的便携包继续完成干净 Windows 安装与双向实课闭环；运行时版本、二进制指纹及可获取的许可文件已记录，签名安装程序、Node.js 完整第三方声明和 FFmpeg 对应源代码的公开分发安排仍需完善。

完成以上验收前，不应宣称“已完整达到设计包全部要求”“原教师音色效果已验收”“所有手写公式可自动正确识别”或承诺固定长课耗时与每课费用。
