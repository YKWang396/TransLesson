# 课译 MathBridge 使用说明

更新日期：2026-10-18。本文对应当前可运行的开发版本；设计目标与实际完成范围见 [实现状态](09-implementation-status.md)。

## 1. 启动程序

在本项目目录中双击 **`Start-MathBridge.cmd`**，打开原生 Windows 桌面窗口。第一次启动为空白项目，不会自动上传课程或下载模型。

也可直接运行 **`dist/MathBridge/MathBridge.exe`**。该便携目录包含 Python、Qt、FFmpeg 和 Node.js/MathJax，无需为此另装开发环境；必须保留整个目录，不能只复制 EXE。已在本机隔离开发工具 PATH 验证，尚未在另一台干净 Windows 机器验收。

如果提示先运行 Setup，先双击 **`Setup-MathBridge.cmd`**，等依赖安装成功后再启动。Setup 需要网络，用于安装 Python 包及本地 MathJax 依赖；它不会下载 Whisper 权重，也不会提交课程内容。安装环境应具备：

- Windows x64、Python 3.11 或 3.12；当前项目要求 Python `>=3.11,<3.14`。
- Node.js 和 npm，或可用的 pnpm。公式讲义通过本地 Node.js/MathJax 排版。
- 可播放的本地课程视频；配音需要 Windows 已安装的目标语言声音。

本文件夹已准备好的 `.venv` 只适用于当前环境；复制到另一台电脑后应重新 Setup。当前启动脚本使用 Python 环境，不能据此视为已通过“干净机器免 Python 安装包”验收。

只做字幕校对时可以暂时不安装语音识别组件。需要本地转写时，在本项目目录打开 PowerShell，执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\setup.ps1 -WithASR
```

这条命令会联网安装可选的 faster-whisper 组件，**模型文件仍须自行提前准备并导入**。

## 2. 建立课程项目

1. 在“01 导入”选择包含画面的课程视频。
2. 为项目选择一个独立文件夹，建议使用空文件夹。项目名称默认取媒体文件名。
3. 选择“英语 → 简体中文”或“简体中文 → 英语”。
4. 点击“建立项目并检查媒体”，等待媒体探测和文件指纹计算完成。

原始媒体通过路径链接到项目，不会整份复制进去。请同时保留原始媒体和项目文件夹。源媒体被移动后，在校对页点击“重连媒体”，选择**内容相同**的文件；程序会核对指纹。同名但内容不同的视频不能继续复用旧项目。

“打开项目”选择包含 `project.json` 的项目目录。即使媒体暂时找不到，已保存的文字仍可校对；播放、配音和视频导出需要先重连媒体。

`examples/project.json` 是人工构造的接口样例，没有随附真实课程视频。不要把它作为已完成处理的课程项目或数学质量证明。

## 3. 两条上手路径

### A. 已有字幕：先走手动校对路径

这条路径可以先验证项目、字幕编辑和导出，不需要下载识别模型，也不需要 API Key。

1. 建立课程项目。
2. 在导入页点击“导入 SRT / VTT 转写”，选择**源语言**字幕。文件应使用 UTF-8 编码。
3. 在“02 校对”选中一行，填写译文、字幕和配音读法。
4. 逐段检查后改为“已确认”。只需要字幕时，到导出页仅勾选 SRT/VTT 后导出。

导入字幕会成为课程的源句，不会直接当作目标译文。时间必须在视频范围内，且字幕不能重叠。当前已有转写的项目不允许在界面中直接覆盖导入；需要重新导入时另建项目，以保护已做的校对。

### B. 本地识别，再手动或 API 翻译

1. 提前准备完整的 **CTranslate2/faster-whisper 多语种模型目录**，至少包含 `model.bin`、`config.json`、`tokenizer.json`。中英双向课程应选多语种模型，避免仅英语的 `.en` 模型。
2. 打开“处理设置 → 本地处理”，选择 Whisper 本地模型目录。当前界面仅提供 CPU / int8 基线；GPU 环境尚须单独验证。
3. 在校对页依次点击“① 本地转写”“② 数学解析”。识别结果和规则提取的公式均是待校对草稿。
4. 选择手动填写译文，或按下一节配置文本 API，再点击“③ 翻译与读法”。

识别时不会因模型缺失而自动上网下载。提示 `MISSING_MODEL` 时先检查模型目录；提示 `MISSING_DEPENDENCY` 时检查可选 faster-whisper 组件。

导入页的“开始自动处理草稿”会按转写/解析/翻译/配音/讲义顺序继续；已有转写时从解析开始。使用前应先配置好模型、文本处理方式及目标语言声音。手动模式不会生成伪翻译，自动流程会在需要自动翻译时提示配置提供程序。

## 4. 可选：使用文本 API

打开“处理设置 → 文本与隐私”：

1. 选择“DeepSeek API”。
2. 填写服务地址、账户可用的模型标识和 API Key。界面中的模型名是可编辑配置，请以自己的服务账户为准。
3. 填写项目预算、最多调用次数和账户当前输入/输出单价。默认单价是估价配置，不能当作服务商价格承诺。
4. 明确勾选“允许向所选 API 发送本次任务所需的课程文本”，再点击“应用设置”。

后续点击翻译任务时，会发送必要的课程源句、文本公式候选、相关术语等文本。当前界面没有开放自动上传原视频、公式截图或参考声音。未授权时外部文本请求会被拒绝，不会静默改用其他提供程序。

Key 默认只留在当前会话。勾选“将 Key 保存在 Windows 凭据库”后，才写入当前 Windows 账户的凭据库；取消保存选项会删除该应用保存的凭据。Key 不写入项目 JSON、普通设置或日志。

文本上传许可和提供程序选择目前属于**应用设置**，会在后续项目中沿用；切换项目时请再次核对。用量分项目累计，Footer 显示费用估计、预算及调用次数。不确定请求会保留预算占用；取消或网络错误不等于服务商没有计费，最终以账户账单为准。

本地 llama.cpp 目前是进阶接口：需自行准备模型、运行仅绑定 `127.0.0.1` 的兼容服务，再选择“本地 llama.cpp”，将 API 地址改为对应的 `http://127.0.0.1:端口/v1` 和实际模型标识。设置页会提示本地服务操作要求，当前版本不会自动启动或回收该服务；没有准备该环境时使用手动模式。

## 5. 校对源句、公式和术语

在“02 校对”选择片段后，下方四个输入框各有用途：

| 输入框 | 用途 | 示例 |
|---|---|---|
| 源句 | 从课程中实际听到的内容 | `Consider x squared plus two x plus one.` |
| 译文 | 保留可追溯的公式 ID | `考虑多项式 {{formula-1}}。` |
| 字幕 | 导出给播放器的纯文本 | `考虑多项式 x² + 2x + 1。` |
| 配音 | 真正让系统声音朗读的文字 | `考虑这个多项式，x 的平方加二 x 加一。` |

没有引用公式的普通句子不需要写占位符。引用公式时，应保留本段已有的 `{{formula-id}}`；不要把这类占位符或裸 LaTeX 填进字幕与读法。

可编辑片段起点、终点和确认状态。起点必须早于终点，不能超出原视频时长，也不能与前后片段重叠。点击片段会让原课定位到该段。

输入会先标记“编辑中”，约 0.65 秒后自动创建新 revision。也可使用“项目 → 提交当前编辑”或 `Ctrl+S`。顶部显示“已保存 · revision …”才表示该次编辑已通过校验并写入。若显示“尚未保存”，请检查时间、必填文字和公式 ID，查看“任务日志”中的具体原因。

“项目 → 撤销上次项目修改”可撤销当前会话内最近的项目编辑，并生成新的 revision；历史快照仍会保留。后台任务运行时也能校对，迟到的旧结果不会覆盖新编辑。

### 公式原图与人工候选

1. 在播放器中定位到公式画面，先选择所属片段。
2. 点击“提取当前帧证据”。
3. 点击“框选并添加公式证据”，在图上拖动选框；可手填 LaTeX，也可留空保留原图。
4. 在右侧双击公式，核对原始表达、LaTeX、两种语言读法及状态。

该框选入口**不会运行自动 OCR**。手写、模糊或存在歧义的式子可选择“保留原始证据”；不要为了通过导出检查而盲目标为确认。右侧来源列表可跳回原音或显示原帧。

右侧双击课程术语可以修改译法和概念上下文，并锁定课程译法。数学规则与模型候选不能代替回听原音、核对变量、符号、条件和积分上下限。

## 6. 多人配音与课程讲义

在“处理设置 → 配音与字幕”选择默认 Windows 声音名称/ID；留空时按目标语言选择已安装声音。在“03 配音”可为每位说话人单独配置系统声音或参考原声音色，然后点击“按说话人生成配音”，完成后点击“试听最新配音”。

### 区分与校对说话人

1. 完成本地转写或导入字幕后，在“02 校对”点击“区分说话人”。自动区分需在“处理设置 → 本地处理”配置本地说话人分段 ONNX 模型、声纹 ONNX 模型及 sherpa-onnx 组件；说话人数填 0 时自动判断，也可填写已知人数。
2. 若希望自动草稿流程也进行区分，勾选“自动处理时，在转写后区分说话人”。模型不会自动下载。
3. 回听原视频，逐段检查表格中的说话人。在片段编辑区的“说话人”下拉框修改归属，输入会按其他片段编辑方式自动保存。
4. 无需模型也可点击“添加”创建说话人，手动为片段分配。在“03 配音”双击说话人可改名和配置声音。

自动结果是草稿。短插话、声音相近、背景噪声及多人同时讲话容易产生歧义；当前不会分离同时重叠的讲话，应回听并人工校对。若一条导入字幕跨越多位说话人，在“源句”中把光标放到交界处，点击“拆分原文片段”并填写对应的视频时间，再为两段分别指定说话人。拆分会清空两段需重新生成的译文、字幕与配音，保留原文供校对。

### 参考原声音色

1. 先准备 GPT-SoVITS 的本地模型并启动其 `api_v2.py` 服务。应用内置调用接口，不内置该服务或克隆模型；详见 [声音后端准备说明](11-voice-backends.md)。
2. 在“处理设置 → 配音与字幕”填写本机服务地址，默认 `http://127.0.0.1:9880`。若服务更换模型，请修改“克隆模型版本”标识，使已有配音按新模型重新生成。
3. 在“03 配音”选中一位说话人，点击“配置选中说话人”，将配音方式改为“参考原声音色 · 本地 GPT-SoVITS”。
4. 填写原视频中 **3–10 秒**的参考起止时间、参考语言，以及片段中实际说出的原话；选择仅该人讲话、清晰且无明显音乐干扰的片段。在已取得声音使用授权后勾选授权项并保存。“克隆语速”默认 1.0，可按需要调整；设置页的系统语速仅用于 Windows 声音。
5. 点击“试听参考原声”检查取样，再点击“试听该人一段配音”检查目标语言读法和声音。为每位说话人分别配置后，再生成整课配音。

克隆尽量保留每人的音色，跨语言效果取决于参考音频与模型，仍需人工试听。Windows 系统声音也支持按人分别选择；留空的说话人声线会使用默认设置。参考片段只交给本机服务，应用不提供远程参考声音上传入口。

若出现目标语言声音不可用，先在 Windows 中准备该语言的系统语音。若出现 `TTS_TOO_LONG`，应缩短实际读法、适当调整语速或修订片段时间；程序不会通过截掉末尾内容来强行塞入。修改读法或声音后需要重新配音。

在“04 讲义”点击“整理 / 更新讲义草稿”，可编辑章节标题、正文和确认状态。双击来源列表可回到课程片段或公式。API 已生成结构化讲义时会沿用其内容；没有结构化讲义时，当前回退方式是把已有译文整理成带来源的片段草稿，仍需人工编辑成课程讲义。

讲义公式也用 `{{formula-id}}` 引用，正文引用须与已有来源匹配。未支持的额外推导、原课未给出的结果不能当作课程事实补入。

## 7. 导出

1. 在“05 导出”选择格式。默认勾选 MP4、SRT、VTT、PDF；只要字幕时可取消其他格式。
2. 选择音轨策略：只用译声、保留原声只加字幕、低音量原声加译声。
3. 点击“刷新检查”，处理阻断问题。双击片段相关问题可跳回对应课程片段。
4. 若使用译声，先生成当前读法对应的配音；若需要 PDF，先整理并核对讲义。
5. 选择输出目录，或留空使用项目的 `exports` 文件夹，再点击“导出所选文件”。

默认 MP4 写入可切换的字幕轨；部分播放器需要手动开启字幕。独立 SRT/VTT 可在其他播放器中加载。当前界面尚未提供完整的烧录位置和公式叠加设置，不能把设置页的字幕位置选择当作已经验证的烧录效果。

点击“生成待校对预览（≤30秒）”会生成开头最多 30 秒的 `preview.mp4` 和配音 WAV。只选取终点不超过 30 秒的完整片段，不会为凑时长截断一段读法；原课不足 30 秒时使用其实际时长。若没有符合范围的完整片段，会提示无法生成，需先调整分段与时间。

预览完成后，在“最近完成的文件”中双击标有“待校对预览”的 `preview.mp4`，使用系统播放器检查字幕、音量、读法与片段衔接。这是待校对草稿，正式发布前仍需检查整片字幕显示、音量和末尾内容。

完成后在“最近完成的文件”中双击打开结果。导出目录包含本次 revision 的清单与检查报告；任务失败或取消时不要把缓存中的临时文件当作正式结果。选择外部输出目录时使用独立 revision 子目录，避免覆盖已有文件。

低音量原声混入时仍有教师原语人声，不能称作干净背景声。当前项目入口要求课程视频；没有视频轨的文件会明确拒绝。

## 8. 常见问题

| 提示或现象 | 处理方式 |
|---|---|
| 启动提示先运行 Setup | 在本项目目录执行 `Setup-MathBridge.cmd`；检查 Python、Node.js 和联网环境。 |
| 模型缺失 | 先安装可选 ASR 组件，再选择完整的本地 Whisper 模型目录。应用不会代下载。 |
| 外部 API 未授权 / Key 错误 | 在“文本与隐私”明确授权并检查账户配置；可改为手动校对继续。 |
| 原视频已移动 / 内容改变 | 使用“重连媒体”选择指纹相同的原文件；内容改变则新建项目。 |
| 公式阻止导出 | 回查来源，确认候选，或保留有效原始图像证据；不要删除来源来绕过检查。 |
| 配音过期 | 更改读法、声音、语速后重新生成配音，再导出。 |
| PDF 缺少 Node / MathJax | 运行 Setup 安装本地依赖；也可先导出字幕继续校对。 |
| PDF 提示缺少静态中文 TTF | 准备可合法使用的中文 TTF，通过环境变量 `MATHBRIDGE_CJK_FONT` 指定路径后重启。 |
| 要中止任务 | 点击“停止任务”，等待进程退出；已保存的文字校对不会丢失。 |
| 窗口关闭稍有等待 | 有任务时程序会先停止后台进程再关闭，避免遗留计算进程。 |

当前版本的真实课程质量、长课稳定性、多人识别准确率、跨语言音色相似度及干净 Windows 发布安装仍需按 [验收标准](05-acceptance.md) 继续验证。工程测试用合成短片只能证明文件和时间轴处理路径，不代表真实数学课程的识别、翻译或听感质量。
