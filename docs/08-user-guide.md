# 操作指南

## 建立与打开项目

双击课译TransLesson.exe。在“01 导入”选择课程视频、独立项目文件夹和翻译方向，建立项目。已有课程使用“打开项目”或“最近项目”，不需要重新选择全部输入。

处理结果默认在项目内保存。源视频保留原位置；移动后可“重连媒体”，程序会核对内容指纹。导出页可以另选保存目录。

## 准备原文

在“处理设置 → 组件与识别”选择组件目录或自定义 Whisper 模型目录，随后开始识别原文。模型目录至少含 `model.bin`、`config.json` 和 `tokenizer.json`，中英课程使用多语种模型。

已有源语言字幕可导入 UTF-8 SRT/VTT，跳过语音识别。已有转写的项目需要另建项目才能覆盖导入，以保护已编辑内容。

## 断句与翻译

在“处理设置 → 文本与隐私”选择服务商，填写对应 Key 和模型，测试连接，设置项目预算并允许发送课程文本。详见 [文本 API](20-multiple-text-apis.md)。

在“02 校对”执行 **AI 断句并翻译**。软件先整理上下文和分句，再处理数学内容及翻译。平时看原文和目标字幕两个框即可；特殊读法、时间、术语和公式放在高级工具中。

无需逐句点击确认全部内容才能试配音。先抽查，再通过问题清单处理缺失译文、公式歧义或其他阻断项。修改字幕会同步可确定的读法；修改公式内容时需要重新核对。

## 配音与试听

在“03 配音”为每位说话人选择系统声音或参考原声音色。参考音色需准备本机 GPT-SoVITS 服务；操作见 [声音配置](11-voice-backends.md)。

点击 **自动生成并匹配配音**。软件自然合成译声、测量时长、利用可用停顿并调整局部速度。静音或疑似漏读会自动重试；仍有问题时显示句子和时间。通过的片段保留，重试时继续处理。

集中试听可比较原声、自然译声和匹配后的译声。时长问题优先检查译文和配音读法，必要时拆合相邻同一说话人的语义单位。不要用删除条件或否定词的方式缩短内容。

## 讲义与导出

在“04 讲义”执行 **AI 教学讲义**，根据课程主题提炼概念、定义、推导和例子。可以编辑章节并跳转到来源。

在“05 导出”选择格式和目录。只要字幕时可直接导出 SRT/VTT；视频或 WAV 需要有效配音。视频可选择只用译声、低音量原声加译声、或保留原声字幕。未确认的公式需核对，或明确选择保留原始证据。

导出后检查开头、末尾及问题句。PDF、字幕和视频可独立使用。项目 JSON 便于继续编辑；它不能代替媒体、模型及整个项目的备份。

## 任务与错误

处理期间显示当前阶段和进度，可停止任务。已完成的有效片段和费用记录保留，再次执行可继续。错误会显示在任务日志或问题清单；按具体缺失项修复后重试。

Key 可选保存在当前 Windows 凭据库，不随项目迁移。API 费用由服务商结算，应用按设置费率估算，达到项目预算后停止后续调用。
