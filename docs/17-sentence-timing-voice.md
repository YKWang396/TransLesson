# 0.1.8：完整断句、前后空挡和多段音色参考

更新日期：2026-10-31。

## 完整断句

每次 AI 断句请求最多 420 个原文词单元、6,500 个原文字符，另外提供有界的前后文。非最终批次会保留最后两句到下一批复核。程序不再把 ASR 逗号或时间段当作必须切分的位置：短句中未完结的从句、条件句、名词短语和数学术语会合回后续内容。特别长的语句仍允许自然分句，保证上下文有界。

修复仅去掉不可靠的边界，不重写原文、不改词序。先整理原文，再翻译完整语义单位；字幕的两行排版由显示层处理，不通过打断原文来凑行数。断句 checkpoint 升级版本，避免复用旧策略产生的边界。

已有课程可在“02 校对”重新进行 AI 断句和翻译。这会产生新的分段和译文，已有讲义引用会重绑并标记待检查；建议先保留项目副本。

## 配音前后空挡

开启“自动匹配原声节奏”时，同一人的连续语句共享局部余量；较长句间空挡也会划分给前后语句。每段空挡只分配一次，保留短停顿，避免两句同时占用或重叠。必要时允许句子提前到前面的空挡，每句起点相对原文最多偏移约两秒。

先使用自然配音和可用空挡，再调整停顿和局部语速。长空挡不再受“句后最多借用 1/2 秒”限制；这个固定限制仅适用于关闭自动匹配的模式。仍不跨越其他人的原声、缺失句子或视频边界。放不下的完整语音继续列入问题清单，不截词、不偷偷提高语速上限。

## 同一说话人的多段参考

在“03 配音 → 配置选中说话人”中勾选“自动补充同一说话人的多段原声”。主参考仍为 3–10 秒，保留准确原话与语言；额外自动选择最多三段互不重叠的同人片段，可逐段回听。已有手动主参考保持不变。

生成时从原视频提取 32 kHz 单声道 PCM 参考，保留原音轨可提供的带宽。供识别使用的 16 kHz 音轨仍用于 ASR 与节奏分析。参考组合或声音提取方式变化后，旧配音缓存会失效，防止把旧声音当作新结果。

课译通过 GPT-SoVITS `api_v2.py` 的 `aux_ref_audio_paths` 传入补充音频。主参考的 `prompt_text` 只对应主音频，不能把多段原话拼接到一段六秒录音后面。当前 v2ProPlus 会使用这些音频的声学参考与说话人表征。

这是合成时的多段参考，不会训练模型。音色相似度还受录音质量、跨语言、参考选取和模型能力影响，多段不保证一定更像；可关闭补充参考进行试听比较。若希望建立老师的专用模型，可再按 GPT-SoVITS 的流程整理更长的干净同人数据并微调，需要单独训练，课译本版不自动训练。

官方接口与能力说明：[GPT-SoVITS API](https://github.com/RVC-Boss/GPT-SoVITS/blob/main/api_v2.py)、[官方项目说明](https://github.com/RVC-Boss/GPT-SoVITS)。原生服务启动命令见 [参考原声配置](16-auto-voice-reference.md)。

## 验证

223 项自动测试通过，覆盖词序与边界保留、重叠窗口、句前句后空挡、缺失语音隔离、多段参考协议和真实原媒体 32 kHz 提取。真实 `test1` 在独立副本重新断句与翻译，4,986 个原文词保持顺序，修复了短条件句和修饰从句被打断的实例。整课音色与自然度仍需人工试听验收。

真实多参考整课验证：366 段全部经本机 v2ProPlus 合成。相同音频在 1.15 倍上限下，改进局部可行组分配将 41 个时长问题降为 14 个；1.35 倍时剩 1 个，1.50 倍时为 0，整课 WAV 已完成且长度等于原视频。1.50 是允许的局部上限，不是把所有语句统一变为 1.50 倍。多段参考和单段参考的三组相同文本样例另存于测试项目，供人工比较。
