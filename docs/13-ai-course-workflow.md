# 0.1.4：AI 断句、翻译与教学讲义

更新日期：2026-10-30。

0.1.4 补齐便携版 Python TLS 证书策略文件，固定使用与解释器匹配的 OpenSSL DLL，修复打包后 API 连接出现 FileNotFoundError 的问题；证书校验保持开启。此前 0.1.3 的便携包请更新到本版。

## 日常操作

1. 用新版打开已有课程项目，或从顶部“最近项目”选择。程序恢复原媒体、字幕、讲义与工作目录；不必重新新建或选择媒体。新建另一课时展开“新建另一个课程项目”，选媒体后自动建议工作目录。
2. 在“处理设置 → 文本与隐私”配置文本 API 和密钥，允许课程文本处理。默认只需设置“本项目最多花费”；断句、翻译和讲义共用项目累计预算。估算单价放在高级选项，实际费用以服务商账单为准。
3. 在“02 校对”点击 **AI 重新断句并翻译**。AI 先理解相邻片段，合并碎句、拆分过长句，再生成译文、字幕和配音读法。无需逐句手填或确认。这个入口会重新生成已有译文，旧版本仍在项目历史中。
4. 在“04 讲义”点击 **AI 生成 / 重新整理教学讲义**。按章节提炼后合成学习概览、定义、推导、课堂例题和小结，移除寒暄和重复话语；来源可双击回听。重新生成替换当前讲义，可撤销。
5. “05 导出”默认把成品放在当前项目的 `exports` 中。需要其他位置时，只在此处选择导出目录；切换课程会清除上个课程的另存位置。

如果翻译中断，主按钮会补齐缺失译文，保留已整理的断句与已有译文。要主动优化全课断句时再点击“AI 重新断句并翻译”。讲义中断可再次点击生成，已完成章节通过 checkpoint 复用。

## 数学显示与时间轴

字幕优先使用无歧义的 `2+3`、`x²`、`Ax=b` 等数学符号，配音使用自然语言。程序补充规范化明确的加、减、乘、等号表达，不计算或化简；分母范围有歧义时保留原表达。复杂或不确定的数学内容仍需抽查。

AI 只能决定原文词之间的分界；程序重建原文，检查顺序、覆盖、说话人和来源引用。分批处理会把末尾未完成的句子带入下一批。新切点优先使用原 ASR 的词时间；没有匹配的词时间时在原片段内部估算，因此仍建议回听衔接。长停顿或说话人变化会形成独立上下文。

已存在的公式证据保留，来源随新片段重绑定。重新断句后配音缓存会因片段及读法变化失效，需要重新生成配音。AI 讲义是草稿；来源检查和字体完整性检查不等于数学内容已被证明正确。

复制项目到新电脑时，如原视频也在项目目录内且指纹一致，程序可自动恢复媒体关联；否则使用“重连媒体”。课程文件与模型仍需单独复制。
